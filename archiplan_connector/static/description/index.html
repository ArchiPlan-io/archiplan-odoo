Production scheduling you set up by talking – now inside Odoo

ArchiPlan is production scheduling for small and mid-sized manufacturers. Describe your shop by voice or text, and it plans every order around your people, machines, shifts and deadlines. When a rush job lands or someone is off, rebuild the plan in one click.

Selected Odoo sales orders go into ArchiPlan, and the live plan appears in Odoo under Manufacturing → Planning.

How it works with Odoo

1. Connect

Create a dedicated read-only Odoo user for ArchiPlan.

2. Pick and preview

Choose the sales orders you want to plan and check the preview before importing.

3. Plan and review

Build the plan in one click and see the schedule in Odoo under Manufacturing → Planning.

Setup

  1. Install ArchiPlan Connector in Odoo.
  2. In Settings, configure the ArchiPlan URL and view-only schedule link.
  3. Use Create ArchiPlan access to generate credentials for a dedicated read-only internal user.
  4. In ArchiPlan, open Orders → Import → From Odoo and connect with those credentials.
  5. Choose orders, review the preview, and import them into ArchiPlan.
